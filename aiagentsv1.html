AI Agent Glossary

Comprehensive definitions of key terms and concepts in AI/ML/LLM systems

Classification vs Generation

Classification tasks involve categorizing inputs into predefined labels, while generation tasks create new content based on learned patterns.

Supervised Learning Output Types

PII (Personally Identifiable Information)

Any data that can identify an individual, such as names, addresses, social security numbers, or biometric data requiring special handling and protection.

Privacy Data Protection

p95 Latency

The 95th percentile of response times, meaning 95% of requests are faster than this value. Critical for measuring system performance under load.

Performance SLA

Model Quantization

Reducing the precision of model weights (e.g., from 32-bit to 8-bit) to decrease memory usage and increase inference speed while maintaining acceptable accuracy.

Optimization Deployment

vLLM

High-throughput, memory-efficient inference engine for large language models with advanced memory management and continuous batching.

Serving Performance

Guardrails

Safety mechanisms that prevent models from generating harmful, inappropriate, or off-topic content through input/output filtering and validation.

Safety Content Policy

Chain of Thought (CoT)

Prompting technique where models are instructed to break down complex problems into step-by-step reasoning before providing final answers.

Prompting Reasoning

Token Usage

Tracking input and output tokens for cost management and performance monitoring in LLM systems.

Monitoring Cost

Semantic Chunking

Breaking documents into meaningful sections based on content similarity rather than fixed sizes, preserving context and relationships.

Document Processing Context

FAISS

Facebook AI Similarity Search - efficient library for similarity search and clustering of dense vectors, optimized for memory usage and speed.

Vector Search Performance

HyDE (Hypothetical Document Embeddings)

Technique that generates hypothetical answer documents before embedding, improving retrieval quality for complex queries.

Retrieval Query Enhancement

CDC (Change Data Capture)

Process of identifying and capturing changes made to data in a database, enabling real-time updates to search indexes.

Data Pipeline Real-time

LoRA (Low-Rank Adaptation)

Parameter-efficient fine-tuning method that updates only a small subset of model parameters, reducing memory and compute requirements.

Fine-tuning Efficiency

DPO (Direct Preference Optimization)

Alignment technique that directly optimizes models based on human preferences without requiring complex reward modeling.

Alignment RLHF Alternative

Reasoning Traces

Step-by-step explanations of model reasoning processes, used as training data to improve model transparency and performance.

Training Data Explainability

Hallucination Tests

Evaluation methods to detect when models generate factually incorrect or fabricated information.

Safety Reliability

Agent Loop

Iterative cycle of planning actions, executing them, observing results, and reflecting on outcomes to improve future performance.

Autonomy Decision Making

Multi-Agent Systems

Systems where multiple AI agents interact, collaborate, or compete to solve complex tasks more effectively than single agents.

Collaboration Scalability

Function Calling

Capability that allows LLMs to call external functions or APIs to perform specific tasks or retrieve real-time information.

Tool Use Integration

Episodic Memory

Memory system that stores and retrieves specific experiences and events, enabling agents to recall past interactions and outcomes.

Memory Context

Jailbreak Detection

Systems that identify attempts to coerce models into breaking their safety rules or generating prohibited content.

Security Adversarial

Prompt Injection

Security vulnerability where malicious instructions are hidden in user inputs to override system prompts and safety measures.

Security Attack Vector

Win Rate

Percentage of successful task completions or correct responses, used to measure overall system effectiveness.

Metrics Performance

Canary Deployment

Gradual rollout strategy where new model versions are released to a small subset of users before full deployment.

Deployment Risk Management

CRM Agents

AI systems that automate customer relationship management tasks like lead qualification, follow-ups, and customer support.

Business Application Automation

OpenAI Assistants

Pre-built AI agents from OpenAI that can be customized with specific instructions, tools, and knowledge bases.

Platform Agent Framework

GPT-4o

OpenAI's multimodal flagship model that processes text, images, and audio with enhanced speed and efficiency.

LLM Multimodal

text-embedding-3

OpenAI's advanced text embedding model that converts text into high-dimensional vectors for semantic search and similarity tasks.

Embeddings Vector Search

Vertex AI

Google Cloud's unified ML platform for building, deploying, and scaling machine learning models and AI applications.

Cloud Platform MLOps

Langfuse

Open-source observability platform for LLM applications, providing tracing, monitoring, and analytics for AI systems.

Observability Monitoring

pgvector

PostgreSQL extension that enables vector similarity search, allowing traditional databases to handle embedding-based queries.

Vector Database PostgreSQL

LangGraph

Framework for building stateful, multi-actor applications with LLMs, enabling complex agent workflows and state management.

Agent Framework State Management

RAGAS (RAG Assessment)

Framework for evaluating Retrieval-Augmented Generation systems, measuring faithfulness, answer relevance, and context precision.

Evaluation RAG Metrics

CPQ (Configure, Price, Quote)

Business process for configuring products, calculating prices, and generating quotes, often automated with AI assistance.

Business Process Sales Automation

Dunning Policies

Automated processes for managing overdue payments, including reminder sequences and escalation procedures.

Finance Collections

KYC/KYB (Know Your Customer/Business)

Compliance processes for verifying customer and business identities to prevent fraud and meet regulatory requirements.

Compliance Identity Verification

ASR (Automatic Speech Recognition)

Technology that converts spoken language into written text, enabling voice-based AI interactions.

Speech Processing Voice AI

IVR (Interactive Voice Response)

Automated phone system that interacts with callers through voice and DTMF tones to route calls and provide information.

Telephony Customer Service

IDP (Intelligent Document Processing)

AI-powered extraction and processing of information from documents, combining OCR, NLP, and computer vision.

Document AI OCR

AP (Accounts Payable)

Business process of managing and paying supplier invoices and expenses, often automated with AI for efficiency.

Finance Invoice Processing

ViT (Vision Transformer)

Neural network architecture that applies transformer models to computer vision tasks, processing images as sequences of patches.

Computer Vision Deep Learning

Churn Prediction

Using machine learning to identify customers likely to stop using a service, enabling proactive retention efforts.

Predictive Analytics Customer Retention

BM25 (Best Matching 25)

Text scoring algorithm that ranks documents based on term frequency and inverse document frequency, commonly used in search engines.

Information Retrieval Search

Prophet

Open-source forecasting library developed by Facebook for time series prediction with automatic trend, seasonality, and holiday detection.

Time Series Forecasting

Buddy Matching

AI system that pairs new employees with experienced colleagues for mentorship and onboarding support.

HR Onboarding

Isolation Forest

Unsupervised anomaly detection algorithm that identifies outliers by isolating them in random forests.

Anomaly Detection Unsupervised Learning

Collaborative Filtering

Recommendation algorithm that predicts user preferences based on similar users' behavior and preferences.

Recommendation Systems Personalization

Lead Times

Time required from order placement to delivery, critical for supply chain planning and inventory management.

Supply Chain Operations

Case Law

Body of judicial decisions and legal precedents that guide future court rulings and legal interpretations.

Legal Precedent

Clinical Guidelines

Evidence-based recommendations for medical practice, developed by medical experts and professional organizations.

Healthcare Evidence-Based
