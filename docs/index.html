What is RAG?

Retrieval-Augmented Generation (RAG) combines the best of retrieval-based and generative AI. It retrieves relevant documents from a knowledge base and uses them as context for LLM generation, resulting in more accurate, factual, and up-to-date responses.

RAG Fundamentals

🔄 The RAG Pipeline

Retrieval-Augmented Generation combines retrieval from external knowledge sources with generative AI. It retrieves relevant documents from a knowledge base and uses them as context for LLM generation, reducing hallucinations and improving factual accuracy.

Core Components

📚 Knowledge Base

Vectorized documents stored in databases like ChromaDB or FAISS

🔍 Retriever

Semantic search using dense embeddings to find relevant chunks

🤖 Generator

LLM that synthesizes answers using retrieved context

Text Chunking Strategies

Fixed-Size Chunking

Simple approach: divide text into equal-sized chunks

Pros: Easy to implement
Cons: May split sentences/paragraphs

Recursive Chunking

Smart splitting: respects document structure (paragraphs → sentences → words)

Pros: Preserves semantic units
Cons: More complex

Vector Embeddings

Embeddings convert text into high-dimensional vectors that capture semantic meaning.

Cosine Similarity Formula: similarity = (A • B) / (|A| × |B|)

Popular Models: all-MiniLM-L6-v2, all-mpnet-base-v2, text-embedding-ada-002

Advanced RAG Techniques

🎯 Multi-Query Retrieval

Generate multiple query variations to retrieve diverse relevant documents. Improves recall by capturing different aspects of the query.

🔄 RAG Fusion

Combine results from multiple retrieval strategies using Reciprocal Rank Fusion (RRF). RRF Score = Σ(1/(k + r)) where k=60, r=rank.

🎭 HyDE (Hypothetical Document Embeddings)

Generate hypothetical documents that would answer the query, then use their embeddings for retrieval. Bridges semantic gaps for abstract queries.

🔍 Self-RAG

The model critiques its own retrieval and generation process. Reduces hallucinations by self-verification and provides confidence scores.

🔧 Query Expansion

Expand the original query with related terms, synonyms, and context. Improves recall by handling vocabulary mismatch.

🕸️ Graph-based RAG

Document Loading & Processing

from langchain.document_loaders import PyPDFLoader, WebBaseLoader from langchain.text_splitter import RecursiveCharacterTextSplitter # Load documents pdf_loader = PyPDFLoader("document.pdf") web_loader = WebBaseLoader("https://example.com") documents = pdf_loader.load() + web_loader.load() # Split documents text_splitter = RecursiveCharacterTextSplitter( chunk_size=1000, chunk_overlap=200 ) chunks = text_splitter.split_documents(documents)

Multi-Query Retrieval

def multi_query_retrieval(query, llm, retriever, num_queries=3): # Generate multiple queries prompt = f"Generate {num_queries} different versions of this query: {query}" query_variations = llm.generate(prompt).split("\\n") all_docs = [] for q in query_variations: docs = retriever.similarity_search(q, k=5) all_docs.extend(docs) # Remove duplicates and rank unique_docs = list(set(all_docs)) return unique_docs[:10]

HyDE Implementation

def hyde_retrieval(query, llm, retriever): # Generate hypothetical document prompt = f"Write a detailed passage that would answer this query: {query}" hypothetical_doc = llm.generate(prompt) # Embed hypothetical document hypo_embedding = embedder.encode(hypothetical_doc) # Find similar real documents similar_docs = retriever.similarity_search_by_vector(hypo_embedding, k=5) return similar_docs

🧠 RAG Fundamentals (Questions 1-20)

1. What is Retrieval-Augmented Generation (RAG)?

Answer: RAG combines retrieval from external knowledge sources with generative AI. It retrieves relevant documents from a knowledge base and uses them as context for LLM generation, reducing hallucinations and improving factual accuracy.

2. How does RAG differ from fine-tuning?

Key Points:
• Fine-tuning: Updates model weights, expensive, limited by training data
• RAG: External knowledge, no model updates, scalable, always current
• Fine-tuning: Domain adaptation, RAG: Factual knowledge injection

3. Explain the RAG pipeline step-by-step

Steps:
1. Document ingestion & chunking
2. Embedding generation & vector storage
3. Query embedding & similarity search
4. Context assembly & prompt construction
5. LLM generation with retrieved context

4. What are the main components of a RAG system?

Components:
• Document Loader/Processor
• Text Splitter/Chunker
• Embedding Model
• Vector Database
• Retriever
• LLM
• Prompt Template
• Output Parser

5. What are vector embeddings and why are they important in RAG?

Answer: Vector embeddings are mathematical representations of text in high-dimensional space that capture semantic meaning. They enable efficient similarity search and allow retrieval of relevant documents based on meaning rather than exact keyword matches.

6. What is cosine similarity and how is it used in RAG?

Formula: similarity = (A • B) / (|A| × |B|)
Usage: Measures similarity between query and document embeddings. Higher values indicate more similar content. Range: -1 to 1, where 1 means identical vectors.

7. What are the advantages of RAG over traditional retrieval systems?

Advantages:
• Combines retrieval precision with generative capabilities
• Reduces hallucinations through grounded responses
• Always up-to-date with latest knowledge
• More interpretable than pure generative models
• Better handling of long-tail queries

8. How does chunking affect RAG performance?

Impact:
• Small chunks: Better precision, may lose context
• Large chunks: Better context, may include irrelevant information
• Overlap: Helps maintain continuity between chunks
• Strategy choice depends on document type and use case

9. What are the limitations of RAG systems?

Limitations:
• Dependent on quality of retrieved documents
• May retrieve irrelevant or outdated information
• Computational overhead of embedding generation
• Requires careful prompt engineering
• Potential for context stuffing issues

10. How do you evaluate RAG system performance?

Metrics:
• Retrieval: Precision@K, Recall@K, MRR, NDCG
• Generation: Faithfulness, Relevance, Coherence
• End-to-end: User satisfaction, Response quality
• Latency and throughput for production systems

11. What is the role of the retriever in RAG?

Role: The retriever finds the most relevant documents from the knowledge base based on semantic similarity to the user query. It acts as the "memory" component that provides context for generation.

12. How does RAG handle out-of-domain queries?

Handling:
• Falls back to base LLM capabilities when no relevant documents found
• Can be configured with confidence thresholds
• May provide disclaimers about limited knowledge
• Better than fine-tuned models for out-of-distribution queries

13. What are different types of text splitters used in RAG?

Types:

• Recursive: Splits by separators (paragraphs → sentences → words)

15. What is the difference between sparse and dense retrieval?

Sparse Retrieval: TF-IDF, BM25 - keyword matching, interpretable
Dense Retrieval: Embeddings + similarity - semantic matching, better for complex queries
Hybrid: Combines both approaches for optimal results

• Low temperature (0.1-0.3): More focused, deterministic responses
• Medium temperature (0.5-0.8): Balanced creativity and coherence
• High temperature (0.9-1.5): More creative, potentially less accurate
• RAG often uses lower temperatures for factual accuracy

Failure Modes:

• Embedding model misalignment with task

🤖 Machine Learning Basics (Questions 36-50)

36. Explain the bias-variance tradeoff

Concept: Balance between model complexity and generalization.
High Bias: Underfitting, simple models, poor training performance
High Variance: Overfitting, complex models, poor generalization
Goal: Find optimal complexity for best generalization to unseen data.

37. What is gradient descent and its variants?

Basic GD: Updates weights using full dataset, slow but stable
SGD: Updates using single examples, faster, noisy convergence
Mini-batch GD: Compromise approach, most commonly used
Adam: Adaptive learning rates with momentum, widely used in deep learning

38. How do you handle imbalanced datasets?

Techniques:
• Resampling: Oversample minority, undersample majority classes
• Class weights: Penalize misclassification of minority class
• SMOTE: Synthetic generation of minority class samples
• Ensemble methods: Balanced random forest
• Anomaly detection approaches for rare classes

39. Explain regularization techniques

L1 (Lasso): Feature selection, sparse models, adds |w| to loss
L2 (Ridge): Prevents overfitting, shrinks weights, adds w² to loss
Elastic Net: Combines L1 and L2 regularization
Dropout: Randomly deactivates neurons during training
Early Stopping: Stops training when validation loss increases

40. What is cross-validation and why is it important?

Purpose: Estimate model performance on unseen data
K-fold CV: Split data into k subsets, train on k-1, test on 1
Benefits: Reduces overfitting to train set, provides confidence intervals
Types: Stratified K-fold, Leave-one-out, Time series split

41. What are the differences between supervised, unsupervised, and reinforcement learning?

Supervised: Labeled data, predict outputs, classification/regression
Unsupervised: Unlabeled data, find patterns, clustering/dimensionality reduction
Reinforcement: Learn through interaction, maximize rewards, game playing/robotics

42. Explain precision, recall, and F1-score

Precision: TP/(TP+FP) - Of predicted positives, how many are correct
Recall: TP/(TP+FN) - Of actual positives, how many were found
F1-Score: 2*(Precision*Recall)/(Precision+Recall) - Harmonic mean of precision and recall
Use: Precision for spam detection, recall for medical diagnosis

43. What is the curse of dimensionality?

Problem: As feature space grows, data becomes sparse, distances become less meaningful
Effects: Overfitting, increased computational complexity, degraded performance
Solutions: Feature selection, dimensionality reduction (PCA, t-SNE), regularization

44. Explain ensemble learning methods

Bagging: Bootstrap aggregation, reduces variance (Random Forest)
Boosting: Sequential learning, reduces bias (AdaBoost, XGBoost)
Stacking: Use predictions as features for meta-learner
Voting: Majority vote for classification, averaging for regression

45. What are the assumptions of linear regression?

Assumptions:
• Linearity: Relationship between features and target is linear
• Independence: Observations are independent
• Homoscedasticity: Constant variance of residuals
• Normality: Residuals are normally distributed
• No multicollinearity: Features are not highly correlated

46. How do you handle missing data?

Methods:
• Deletion: Remove rows/columns with missing data
• Mean/Median/Mode imputation: Fill with central tendency
• KNN imputation: Use similar instances to fill missing values
• Model-based imputation: Predict missing values
• Indicator variables: Flag missing values as separate feature

47. What is feature engineering?

Process: Creating new features or transforming existing ones to improve model performance
Techniques: Scaling/normalization, encoding categorical variables, creating interaction features
Benefits: Better model performance, domain knowledge incorporation, reduced dimensionality

48. Explain A/B testing and its statistical significance

Concept: Compare two versions to determine which performs better
Statistical Significance: Probability that observed difference is not due to chance
p-value: Probability of observing results if null hypothesis is true
Confidence Interval: Range where true effect likely lies

49. What are the trade-offs between different ML algorithms?

Decision Trees: Interpretable, handle mixed data, prone to overfitting
Neural Networks: High performance, require lots of data, black box
SVM: Effective in high dimensions, memory intensive, kernel choice important
Linear Models: Fast, interpretable, assume linearity

50. How do you detect and handle outliers?

Detection Methods:
• Statistical: Z-score, IQR method
• Visualization: Box plots, scatter plots
• ML-based: Isolation Forest, Local Outlier Factor
Handling: Remove, transform, treat as separate class, robust models

🧠 Deep Learning & Neural Networks (Questions 51-60)

51. What is backpropagation and how does it work?

Concept: Algorithm for training neural networks by computing gradients
Process: Forward pass → compute loss → backward pass → update weights
Chain Rule: ∂L/∂w = ∂L/∂a * ∂a/∂z * ∂z/∂w
Vanishing Gradient: Gradients become very small in deep networks

52. Explain different activation functions

Sigmoid: (0,1), smooth, vanishing gradients
Tanh: (-1,1), zero-centered, still vanishing gradients
ReLU: max(0,x), solves vanishing gradients, dying neurons
Leaky ReLU: max(αx,x), fixes dying neurons
Softmax: Multi-class classification, outputs probabilities

53. What is the vanishing gradient problem?

Problem: Gradients become exponentially small as they propagate backward in deep networks
Causes: Sigmoid/tanh activation functions, deep architectures
Solutions: ReLU activation, batch normalization, residual connections, LSTM/GRU for sequences

54. Explain convolutional neural networks (CNNs)

Components:
• Convolutional layers: Extract spatial features with filters
• Pooling layers: Reduce dimensionality, translation invariance
• Fully connected layers: Classification from extracted features
Advantages: Parameter sharing, translation invariance, hierarchical feature learning

55. What are recurrent neural networks (RNNs)?

Concept: Networks with memory for sequential data
Architecture: Hidden state carries information across time steps
Problems: Vanishing gradients, long-term dependencies
Solutions: LSTM (long short-term memory), GRU (gated recurrent unit)

56. Explain attention mechanisms

Concept: Learn to focus on relevant parts of input
Self-Attention: Attend to different positions in same sequence
Cross-Attention: Attend to different modality/sequence
Transformer: Entirely attention-based architecture
Benefits: Parallel processing, long-range dependencies, interpretability

57. What is transfer learning?

Concept: Use knowledge from one task to improve performance on another
Approaches:
• Feature extraction: Use pre-trained model as fixed feature extractor
• Fine-tuning: Update some/all layers for new task
• Domain adaptation: Adapt model to new domain with minimal data

58. Explain batch normalization

Concept: Normalize layer inputs to have zero mean and unit variance
Benefits: Faster training, reduces internal covariate shift, allows higher learning rates
Training vs Inference: Uses running statistics during inference

59. What are autoencoders?

Concept: Neural networks that learn efficient data representations
Architecture: Encoder compresses input, decoder reconstructs output
Types: Undercomplete, sparse, denoising, variational
Applications: Dimensionality reduction, anomaly detection, generative modeling

60. Explain the transformer architecture

Components:
• Self-attention mechanism for contextual understanding
• Multi-head attention for different representation subspaces
• Position encoding for sequence order information
• Feed-forward networks for transformation
Advantages: Parallel processing, long-range dependencies, scalability

🗄️ Vector Databases & Embeddings (Questions 61-70)

61. What are vector databases and why are they important for RAG?

Concept: Specialized databases optimized for high-dimensional vector similarity search
Importance: Enable efficient retrieval of semantically similar documents
Features: ANN algorithms, metadata filtering, horizontal scaling

62. Explain Approximate Nearest Neighbor (ANN) search

Concept: Find approximate nearest neighbors in high-dimensional space
Algorithms: HNSW, IVF, LSH
Trade-off: Speed vs accuracy
Use Case: Real-time similarity search at scale

63. What is HNSW (Hierarchical Navigable Small World)?

Concept: Graph-based ANN algorithm with hierarchical layers
How it works: Multi-layer graph with decreasing connectivity
Advantages: High recall, fast search, good for real-time applications
Used in: Pinecone, Weaviate, Qdrant

64. Compare ChromaDB, FAISS, and Pinecone

ChromaDB: Open-source, Python-native, good for small to medium datasets
FAISS: Facebook AI library, optimized for large datasets, in-memory
Pinecone: Managed cloud service, serverless scaling, enterprise features

65. What are different embedding models and their trade-offs?

all-MiniLM-L6-v2: Fast, balanced performance, 384 dimensions
all-mpnet-base-v2: Higher quality, 768 dimensions, slower
text-embedding-ada-002: OpenAI model, high quality, API costs
instructor-xl: Task-specific embeddings, domain adaptation

66. How do you choose the right embedding dimension?

Factors:
• Task complexity: More complex tasks need higher dimensions
• Computational constraints: Higher dimensions = more compute
• Dataset size: Larger datasets can support higher dimensions
• Downstream performance: Balance quality vs efficiency

67. What is embedding quantization?

Concept: Reduce embedding precision to save memory and computation
Types: Scalar quantization, product quantization, binary quantization
Benefits: 2-4x memory reduction, faster search
Trade-off: Slight accuracy loss

68. Explain vector indexing strategies

Flat Index: Brute force search, exact but slow
IVF (Inverted File): Cluster-based partitioning, faster approximate search
HNSW: Graph-based navigation, high performance
Composite: Combine multiple strategies for optimal results

69. How do you handle dynamic document updates in vector databases?

Strategies:
• Incremental updates: Add new vectors without full rebuild
• Version control: Maintain document versions and timestamps
• Soft deletes: Mark documents as deleted without physical removal
• Batch updates: Process updates in batches for efficiency

70. What are hybrid search approaches?

Concept: Combine multiple retrieval strategies for better results
Methods: Sparse + dense retrieval, keyword + semantic search
Benefits: Combines strengths of different approaches
Implementation: Reciprocal rank fusion, linear combination

• Role assignment (system messages)
• Chain-of-thought prompting
• Self-consistency checking
• Instruction tuning
• Context formatting
• Output format specification

94. How do you handle prompt injection attacks?

Risks: Malicious users can override system instructions
Defenses:
• Input sanitization and validation
• Clear system prompt boundaries
• Content filtering and moderation
• Rate limiting and abuse detection
• Sandboxed execution environments

95. What are the ethical considerations in RAG systems?

Considerations:
• Bias amplification from training data
• Privacy concerns with document storage
• Intellectual property and copyright issues
• Misinformation and hallucination risks
• Transparency and explainability requirements
• Fairness and discrimination concerns

96. How do you ensure fairness in RAG systems?

Approaches:
• Diverse data sources and perspectives
• Bias detection and mitigation
• Fairness-aware retrieval algorithms
• Regular audits and monitoring
• Inclusive design and testing
• Stakeholder engagement and feedback

97. What are the privacy implications of RAG?

Implications:
• Document content storage and retention
• User query logging and analysis
• Data leakage through model outputs
• Cross-contamination between users
• Compliance with privacy regulations (GDPR, CCPA)
• Data minimization and purpose limitation

98. How do you implement content moderation in RAG systems?

Strategies:
• Input filtering and sanitization
• Output content checking
• User behavior monitoring
• Automated content classification
• Human-in-the-loop review processes
• Integration with external moderation services

99. What is explainability in RAG systems?

Concept: Ability to understand and explain system decisions
Components:
• Retrieval explanation (why these documents?)
• Generation explanation (why this answer?)
• Confidence scores and uncertainty quantification
• Source attribution and provenance
• User-friendly explanations

100. How do you balance innovation with responsible AI in RAG development?

Balance:
• Ethical guidelines and review processes
• Risk assessment frameworks
• Stakeholder engagement
• Transparency and accountability
• Continuous monitoring and improvement
• Regulatory compliance and industry standards
